# fps_uncap

[English](README.en.md)

> [!NOTE]
> この Mod は [Steam 版『侍道4』](https://store.steampowered.com/app/312780/4/?l=japanese)専用です。

『侍道4』の 30FPS の上限を外し、60FPS で遊べるようにする Mod です。

> [!WARNING]
> **試作です。** ゲームでの動作はまだ確かめておらず、Release にも入れていません。

## 機能

- イベントやカットインも含めて、ゲーム全体を 60FPS にします。キャラクター・カメラ・イベントの進み・メニューやアイコンの動き、キーを押し続けたときのカーソルの送りは、30FPS のときと同じ速さになるように合わせます。
- ゲームのファイルは書き換えず、メモリの上だけで変えます。

## 制約

- 60FPS を保てない PC では、ゲームの進みが遅くなります。
- カメラの揺れなど、一部の動きは 30FPS のときより速く見えることがあります。
- 一部の処理は、フレームを数えて時間を測っています。こうした処理の一部はまだ直していないので、速さが 30FPS のときと違うことがあります。

## インストール（開発版）

> [!WARNING]
> 事前に [wots4-mods（ModLoader）](https://github.com/nagataaaas/wots4-mods) を導入してください。

試作のため、Release にはまだ入れていません。次の [ビルド](#ビルド) の手順でビルドしてから入れてください。

1. ゲームを終了してください。
2. ビルドで得られた `build/game/mods/fps_uncap/` フォルダを、侍道4のインストールフォルダ（`WayOfTheSamurai4.exe` がある場所）の `mods` フォルダへコピーしてください。
3. `{侍道4インストールフォルダ}/mods/fps_uncap/mod.dll` があることを確認し、ゲームを起動してください。

## アンインストール

1. ゲームを終了してください。
2. `{侍道4インストールフォルダ}/mods/fps_uncap/` フォルダを削除してください。

## ビルド

ふつうは [wots4-mods](https://github.com/nagataaaas/wots4-mods) の中でビルドします。この Mod だけをビルドするときは、`-DWOTS4_SDK_DIR=<wots4-mods のパス>` を付けて CMake を実行します。
