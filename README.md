# fps_uncap

[English](README.en.md)

> [!NOTE]
> この Mod は [Steam 版『侍道4』](https://store.steampowered.com/app/312780/4/?l=japanese)専用です。

『侍道4』の 30FPS の上限を外し、60・90・120FPS で遊べるようにする Mod です。

## 機能

- イベントやカットインも含めて、ゲーム全体を選んだ FPS で動かします。キャラクター・カメラ・イベントの進み・メニューやアイコンの動き、キーを押し続けたときのカーソルの送りは、30FPS のときと同じ速さになるように合わせます。
- FPS はオプションで選べます。選んだ時点で切り替わります。
- ゲームのファイルは書き換えず、メモリの上だけで変えます。

## 制約

- 選んだ FPS を保てない PC では、ゲームの進みが遅くなります。
- カメラの揺れなど、一部の動きは 30FPS のときより速く見えることがあります。
- 一部の処理は、フレームを数えて時間を測っています。こうした処理の一部はまだ直していないので、速さが 30FPS のときと違うことがあります。

## インストール

> [!WARNING]
> 先に [wots4-mods（ModLoader）](https://github.com/nagataaaas/wots4-mods) を導入してください。

1. ゲームを終了します。
2. [Releases](../../releases) から `wots4-mod-fps-uncap-<バージョン>.zip` をダウンロードし、解凍します。
3. 解凍してできた `mods` フォルダを、侍道4のインストールフォルダ（`WayOfTheSamurai4.exe` があるフォルダ）にコピーします。すでに `mods` フォルダがある場合は、その中に中身を追加してください。
4. `{侍道4インストールフォルダ}/mods/fps_uncap/mod.dll` があることを確かめてから、ゲームを起動します。

## アンインストール

1. ゲームを終了します。
2. `{侍道4インストールフォルダ}/mods/fps_uncap/` フォルダを削除します。中の設定（`config.ini`）も消えます。

## 設定

タイトル画面のオプション、またはポーズメニューの「各種設定」に追加される「フレームレート」ページ（英語のゲームでは「Frame Rate」）で選びます。選んだ FPS はすぐに反映されます。

| 項目 | 選択肢 | 既定値 |
| --- | --- | --- |
| フレームレート | 30 FPS / 60 FPS / 90 FPS / 120 FPS | 60 FPS |

30 FPS はゲーム本来の速さです。

変更した設定は、ゲームがオプションを保存するときに `{侍道4インストールフォルダ}/mods/fps_uncap/config.ini` に保存され、次回の起動時にも引き継がれます。`config.ini` の `[frame_rate]` の `fps` に 30・60・90・120 のいずれかを書いて変えることもできます（ゲームの再起動で反映されます）。
